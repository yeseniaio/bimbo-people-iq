# Track 2 - Guia para Crear tu AI/BI Dashboard

Paso a paso para construir un dashboard AI/BI en el workspace, conectarlo a los datos de
People, agregar visualizaciones y filtros, usar las capacidades de IA (text-to-viz,
forecasting, key drivers) y activar Genie/Q&A para que los lideres pregunten en lenguaje
natural.

- Metricas y datasets por escenario: [Guia de Datos para Dashboard](01.%20Guia-Datos-Dashboard.md)
- Referencia de columnas: [Catalogo de Tablas](../Track%203%20-%20Databricks%20App/01.%20Catalogo-Tablas.md)

**Workspace:** `https://adb-709692038187649.9.azuredatabricks.net`
**Catalogo/Schema:** `cat_poc_sandbox_peopleai` / `hackaton_2026_people_ai`

## Que es un AI/BI Dashboard

Es el tablero nativo de Databricks (antes "Lakeview"): visualizaciones interactivas sobre
tus tablas gobernadas por Unity Catalog, incluido con Databricks SQL (sin licencia extra).
Trae IA integrada: crear graficos con lenguaje natural, pronosticar tendencias, explicar
"por que" (key drivers) y un boton "Pregunta a Genie" para Q&A.

**Usa AI/BI Dashboard cuando** quieres KPIs, graficos y filtros de solo lectura sobre las
tablas. Si necesitas escritura de datos, UI a la medida o un chat como experiencia
principal, ese es el **Track 3 (Databricks App)**.

## Paso 1: Crear el dashboard

1. En el workspace, menu lateral: **Dashboards** > **Create dashboard**.
2. Ponle nombre, ej. `People AI - Experiencia del Colaborador - <Equipo>`.
3. Se abren dos pestanias: **Canvas** (disenio) y **Data** (datasets).

## Paso 2: Definir el dataset (los datos)

1. Ve a la pestania **Data** > **Create from SQL**.
2. Pega una query de la [Guia de Datos](01.%20Guia-Datos-Dashboard.md). Ejemplo:
   ```sql
   SELECT year, dimention,
          ROUND(100.0*SUM(CASE WHEN favorability='Favorable' THEN 1 END)/COUNT(*),1) AS pct_favorable,
          COUNT(*) AS respuestas
   FROM cat_poc_sandbox_peopleai.hackaton_2026_people_ai.tbl_yl_sayit
   WHERE scale='Likert' AND dimention <> ''
   GROUP BY year, dimention
   ORDER BY year, pct_favorable;
   ```
3. **Run** para validar que regresa datos. Nombra el dataset (ej. `clima`).
4. Repite para cada dataset que necesites. **Consejo:** menos datasets, mas anchos, para que
   el clic en un grafico filtre a los demas (cross-filter).

## Paso 3: Agregar visualizaciones (Canvas)

En **Canvas**, arrastra widgets desde la barra superior. Para cada uno, elige el dataset y
mapea los campos (ejes X/Y, color, valor):

| Widget | Uso tipico en People | Campos |
|--------|----------------------|--------|
| **Counter (KPI)** | % Favorable global, # bajas, # alto potencial | valor agregado |
| **Line** | Tendencia de clima o rotacion en el tiempo | X=`mes`/`year`, Y=metrica |
| **Bar** | Comparar areas, niveles, dimensiones | X=dimension, Y=metrica, color=serie |
| **Pie** | Distribucion (tipo de baja, generacion) | angulo=metrica, color=categoria |
| **Table** | Detalle / alta cardinalidad (puestos, personas) | columnas |
| **Pivot** | 9-box (potencial x desempenio) con color | filas/columnas/valor |

- Cardinalidad: usa color/series con **3-8** valores; lo demas va en tabla.
- KPIs con altura 3-4; graficos con altura 5-6.

## Paso 4: Agregar filtros

Arrastra un widget **Filter** y enlazalo a un campo. Filtros utiles para People:

| Filtro | Campo | Tipo |
|--------|-------|------|
| Area funcional | `grupo_area_funcional` | multi-select |
| Nivel | `nivel` | multi-select |
| Generacion | `generacion` | single/multi-select |
| Anio | `year` | single-select |
| Fecha de cierre | `fecha_de_cierre` | date-range |

> **Regla clave:** un filtro solo afecta a los datasets que **contienen ese campo**. Si un
> dataset esta pre-agregado y no trae la columna, no se filtra. Incluye el campo en el
> `GROUP BY`/`SELECT` de los datasets que quieras filtrar.

## Paso 5: Usar la IA integrada

- **Text-to-viz:** en Canvas, describe en lenguaje natural el grafico que quieres y AI/BI lo
  genera ("tendencia de % favorable por dimension y anio").
- **Forecast:** en un grafico de linea temporal, activa el pronostico con pocos clics (o usa
  `AI_FORECAST` en el dataset). Util para proyectar rotacion o headcount.
- **Key drivers / explicar:** clic derecho sobre un punto o barra > "Explicar" para ver los
  factores que mueven la metrica.
- **Q&A por consumidor:** el usuario puede escribir preguntas de seguimiento sobre el
  dashboard sin salir de el.

## Paso 6: Publicar y compartir

1. Boton **Publish** (arriba a la derecha).
2. **Share** > agrega a los usuarios de negocio (rol de solo lectura / consumidor).
3. Para audiencias amplias, usa **Share to account**. Los usuarios de negocio no necesitan
   entrar al workspace tecnico: acceden desde **Databricks One**.

## Paso 7: Activar Genie / "Ask" sobre el dashboard

Para que los lideres hagan preguntas en lenguaje natural mas alla de lo que ya se ve:

1. Crea un Genie Space sobre las mismas tablas (ver [Track 1](../Track%201%20-%20Genie%20Space/02.%20Guia-Crear-Genie-Space.md)).
2. En el dashboard, activa **Ask Genie** y enlaza ese Space (por su ID).
3. Ahora el usuario tiene un boton para conversar: "por que subio la rotacion en Supply
   Chain?", "compara el clima entre areas". Esto convierte un dashboard descriptivo en una
   experiencia conversacional (justo el objetivo del Escenario 4).

## Ejemplo completo: "Experiencia del Colaborador"

Un dashboard de una pagina, escenario mejor soportado por el dato.

**Datasets (pestania Data):**
- `clima` = Dataset A de la [Guia de Datos](01.%20Guia-Datos-Dashboard.md) (clima por dimension y anio).
- `rotacion` = Dataset B (rotacion mensual por tipo).
- `areas` = cobertura/headcount por area (dataset del Escenario 4).

**Canvas (de arriba a abajo):**
1. **Texto (w=12):** titulo "Experiencia del Colaborador - People AI".
2. **3 KPIs (w=4 c/u):**
   - % Favorable 2025 (dataset `clima`, promedio de `pct_favorable` filtrado year=2025).
   - Bajas totales (dataset `rotacion`, suma de `bajas`).
   - % rotacion voluntaria (derivado en el dataset).
3. **Line (w=6):** tendencia de `pct_favorable` por `dimention` (color) a lo largo de `year`.
4. **Bar (w=6):** `bajas` por `mes` y `tipo_de_baja` (color).
5. **Bar (w=12):** `pct_evaluado` / headcount por `grupo_area_funcional` (dataset `areas`),
   para leer el cruce clima-rotacion-cobertura por area.

**Filtros (arriba):** `year` (single), `grupo_area_funcional` (multi).

**IA:** activa forecast en la linea de rotacion; enlaza un Genie Space para "Ask".

**Historia del pitch:** "El clima cae en la dimension X en 2025; las areas con menor
favorabilidad concentran la rotacion voluntaria; aqui el lider pregunta a Genie por que y
recibe la explicacion." Problema - Solucion - Demo en vivo - Impacto.

## Troubleshooting

| Problema | Solucion |
|----------|----------|
| El grafico dice "no fields to visualize" | El nombre del campo en el widget debe coincidir con la columna/alias del dataset |
| El % sale como 56.1 en vez de 56.1% | Formatea como numero, o divide entre 100 y usa formato porcentaje (0-1) |
| Un filtro no afecta a un widget | Ese dataset no contiene el campo del filtro: agregalo al SELECT/GROUP BY |
| La grafica de clima se ve "plana" | El rango de % es chico: usa KPI con comparacion o tabla, o enfoca la varianza |
| Muchas categorias ilegibles | Cardinalidad alta: agrupa (Top-N + "Otros") o usa tabla |
| `tbl_yl_sayit` con valores raros | Filtra `scale='Likert'` (el texto abierto trae columnas desalineadas) |
| Etiquetas de talento duplicadas por casing | Normaliza con `UPPER(TRIM(...))` en el dataset |

## Tips para la demo de 3 min

1. Abre el dashboard **publicado** (no el borrador).
2. Empieza por el KPI y el insight, no por como lo construiste.
3. Haz **un** clic de cross-filter en vivo (ej. clic en un area) para mostrar interactividad.
4. Cierra con una pregunta a **Genie** en vivo.
5. Menciona privacidad: todo agregado, sin PII individual.
